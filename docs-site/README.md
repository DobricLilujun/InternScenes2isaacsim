# SAGE-Bench documentation site

A dependency-free (stdlib-only) static site for **SAGE-Bench — Scene-graph
Assessment &amp; Generation Evaluation**. It is served by GitHub Pages at
**https://dobriclilujun.github.io/SAGE-Bench**.

## Build

```sh
cd docs-site
python3 build.py            # -> docs-site/output/
```

No packages to install. The builder:

- reads the markdown sources under `source/`
- converts Markdown → HTML (headings, code blocks, tables, lists, blockquotes,
  links, inline code, raw-HTML passthrough)
- generates a full-text **search index** (`assets/search-index.json`)
- wraps every page in the robotic / CV theme (`assets/style.css`)
- bundles a custom **logo** (`assets/logo.svg`) and client-side search
  (`assets/search.js`, powered by Lunr.js)

The output in `output/` is the complete, self-contained site ready to serve.

## Deploy to GitHub Pages

A GitHub Actions workflow (`.github/workflows/pages.yml`) builds the site on
every push and publishes `docs-site/output/` to GitHub Pages. To get the
target URL, either:

1. **Rename this repo to `SAGE-Bench`**, or
2. **Create a repo named `SAGE-Bench`** and point its Pages source at this
   workflow (Settings → Pages → Source: **GitHub Actions**).

Then the site is live at `https://dobriclilujun.github.io/SAGE-Bench`.

## Structure

```text
docs-site/
  build.py            # stdlib-only builder
  source/            # markdown sources (the open-source doc split)
  assets/
    logo.svg         # custom logo (robotic + CV style)
    style.css        # robotic / CV theme
    search.js        # Lunr.js search + substring fallback
  output/            # built site (gitignored — regenerated by build.py)
```
